* [2026-04-28] Dev Log: /api/oauth/usage Contract Cross-Reference     :statusline:oauth:api-contract:

** Context
Three implementations call =GET /api/oauth/usage=: statusline.sh (bash), Claude Code CLI
v2.1.76 (Node/cli.js), and Claude Code CLI v2.1.121 (Bun binary). Two http-spec files
document the endpoint: =specs/claude-code-api-complete.http= and =specs/claude-oauth-api.http=.

** Why
statusline.sh was written against an older version of the CLI. This analysis pins the
exact contract differences so deviations can be corrected and the http-spec kept accurate.

** What
- =UNNECESSARY= stale =anthropic-beta: oauth-2025-04-20= header in statusline.sh usage call
  (line 350 of statusline.sh) — endpoint is GA, neither CLI version sends this header
- =DOCS= =claude-oauth-api.http= falsely documents =anthropic-beta: oauth-2025-04-20= on
  =GET /api/oauth/usage= (lines 263, 285) — contradicts actual CLI behavior
- =RELIABILITY= v2.1.121 added =uE()= retry-on-401 wrapper; statusline.sh has no equivalent —
  token expiry causes silent fallback to stale cache for up to 120s
- =DOCS= =claude-code-api-complete.http= correctly omits the beta flag on =GET /api/oauth/usage=
  (line 335+) — no change needed

** Result
*** Outcome
- statusline.sh sends one extraneous header (=anthropic-beta: oauth-2025-04-20=) on =GET
  /api/oauth/usage=. Server accepts and ignores it. Functionally harmless; misleading in code.
- =claude-oauth-api.http= documents that same extraneous header on two usage endpoint variants
  (lines 263, 285). =claude-code-api-complete.http= is already correct (no beta flag).
- v2.1.121's =uE()= retry wrapper is a deliberate CLI improvement. statusline.sh intentionally
  does not replicate it; the 120s error backoff + cache fallback is the accepted degradation
  model for a status display.

** Notes
*** Known Limitation
When the OAuth access token expires mid-session:
- CLI v2.1.121: =uE()= refreshes the token and retries transparently.
- statusline.sh: the 200→non-200 transition writes =${session_id}.err=, triggers 120s backoff,
  and falls back to the last cached response. Max stale window = cache TTL + 120s backoff.
  This is by design.

*** Gotchas
- =anthropic-beta: oauth-2025-04-20= was required when the usage endpoint was behind the OAuth
  beta gate. The gate was removed; the header was not cleaned up from statusline.sh or the
  oauth-api spec at that time.
- =claude-oauth-api.http= defines =@oauthBeta = oauth-2025-04-20= at line 22 and uses it via
  variable reference on several other endpoints that still legitimately require it. The variable
  definition itself stays; only the two =anthropic-beta: {{oauthBeta}}= lines on the usage
  endpoint blocks should be removed.
